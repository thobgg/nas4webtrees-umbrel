# nas4webtrees – Umbrel community app store

Adds [nas4webtrees](https://github.com/thobgg/nas4webtrees) to umbrelOS: the original, unmodified webtrees
(online genealogy) with SQLite, a short setup page, nightly GEDCOM backups and api4webtrees for the wtWin,
wtTux and wtAnd apps.

**Install:** umbrelOS → App Store → ⋯ (top right) → *Community App Stores* → paste
`https://github.com/thobgg/nas4webtrees-umbrel` → *Add* → open the store → *nas4webtrees* → *Install*.
Then open the app and fill in the setup page.

Community project, not an official part of webtrees or Umbrel.
